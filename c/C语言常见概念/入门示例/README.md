# 入门示例

本组示例从程序结构逐步讲到输入输出、字符和控制流，供第一次学习 C 的读者按顺序阅读。每个源文件都是独立程序，拥有自己的 main 入口，不应把多个文件当作同一个程序拼在一起。

前置知识：能识别基本数学表达式和简单变量。
环境要求：符合 C99 或更新版本的 C 实现，以及标准输入输出和字符串库。

## 推荐阅读顺序

| 顺序 | 示例 | 主要观察点 |
| --- | --- | --- |
| 1 | [程序结构](01_program_structure.c) | main 入口、变量初始化、printf 与返回状态 |
| 2 | [变量与函数](02_variables_and_functions.c) | 声明、初始化、函数实参与形参、返回值；注释中有关键字命名的编译期反例 |
| 3 | [输入与输出](03_input_and_output.c) | scanf 的地址参数、赋值数量检查和错误分支 |
| 4 | [注释](04_comments.c) | 行注释、块注释、字符串里的注释符和不能嵌套的块注释 |
| 5 | [字符与字符串](05_characters_and_strings.c) | 执行字符值、数字字符、零字符、NULL、strlen 与 sizeof |
| 6 | [转义序列](06_escape_sequences.c) | 换行、制表、引号和反斜杠 |
| 7 | [控制流程](07_control_flow.c) | if、switch、for、while、do...while、break、continue 与 goto |

建议先预测每个固定数据示例会走哪条路径，再对照文件末尾的输入与预期结果。带“受控编译反例”的代码保持为注释；完整示例本身应可以正常编译和运行。
