# 入门示例

本目录按建议顺序介绍 C 程序结构、函数、输入输出、注释、字符和控制流程。每个 .c 文件都是独立程序，各自定义 main；不要把多个示例文件链接成同一个程序。

前置知识：能读懂简单数学表达式。示例使用 C99 或更新标准以及标准输入输出、字符串库。

## 阅读顺序

| 顺序 | 示例 | 主要内容 |
| --- | --- | --- |
| 1 | [程序结构](01_program_structure.c) | main 入口、整数变量、printf 与返回状态 |
| 2 | [变量与函数](02_variables_and_functions.c) | 初始化、按值传参、函数返回值和关键字编译反例 |
| 3 | [输入与输出](03_input_and_output.c) | scanf 地址参数、返回值检查和错误分支 |
| 4 | [注释](04_comments.c) | 行注释、块注释、字符串中的注释符和嵌套误区 |
| 5 | [字符与字符串](05_characters_and_strings.c) | 数字字符、零字符、NULL、strlen 与 sizeof |
| 6 | [转义序列](06_escape_sequences.c) | 换行、制表、引号和反斜杠 |
| 7 | [简单控制流程](control_flow_basics.c) | if 分支与 for 累加 |
| 8 | [综合控制流程](07_control_flow.c) | switch、三种循环、break、continue 与 goto |

先读简单控制流程，再把综合示例当作复习。每份完整程序末尾列有示例输入和预期输出；输入失败分支、编译反例和环境相关结果均有标注。
